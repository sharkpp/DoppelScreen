# DOPPEL SCREEN

PCもしくはモバイル端末のリモートスクリーンソフトウエアです。

# 機能

- 画面をリアルタイムに配信し、**ブラウザだけ**で表示する（専用ビューアアプリは不要）
- WebRTC による直接接続。映像と入力はホストとビューアの間を直接流れ、サーバを経由しない
- ブラウザ側からの遠隔操作（左クリック / 右クリック / スクロール / キーボード / 日本語入力）
- タッチ操作へのマッピング（タップ → 左クリック、長押し → 右クリック、2 本指 → スクロール）
- 配信ホストは macOS / Windows / Android / iOS で動作（iOS は閲覧専用）
