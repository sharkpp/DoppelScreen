## 決定事項

- **§11-1 QR の既定は HTTP のまま。** 証明書の警告が出ず、成立する環境では最良。使えない環境は
  ビューアの自己診断が HTTPS へ誘導する。HTTPS の QR / URL はホスト UI に常時併記
- **§11-7 文言の出どころは `i18n/<言語>.yaml` の 1 か所。** macOS は `.strings` を吐いて言語選択を
  OS に任せ、ビューアは単一 HTML で配信する都合上、全言語を埋め込んで読み込み時に 1 回選ぶ。
  **生成物はコミットする**（しないと macOS のビルドに Node が要る）
- **ホスト → ビューアのエラーは文言ではなくコードで送る。** ホストとビューアの表示言語は
  一致しない（Mac は日本語・iPad は英語が普通にある）
- **§11-9 本体は MIT。** libwebrtc（BSD 3-Clause）/ swift-*（Apache-2.0）と両立する。
  別軸で残るのは H.264 の特許（Via LA）だが、符号化も復号も OS が行うため現状のリスクは低い
- **再接続チケットの寿命は接続トークンの期限と独立**（10 分 / 5 分）。長く映しているうちに
  トークンが回っても、繋ぎっぱなしのビューアが切れてはいけない
- **Swift のテストバンドルはアプリをテストホストにしない。** `Sources`（`App/` を除く）を
  直接取り込む。TCC と UI が絡むと CI に載らない

## 捨てた選択肢と理由

- **`contentHint`（SPEC.md §7.2 の表にある）を当てる** → **当てない。** W3C の送出側 API で、
  libwebrtc の Objective-C SDK の `RTCVideoTrack` に対応するプロパティがない。
  意図していた挙動は `degradationPreference` と上限 fps で表す
- **QR 生成に外部ライブラリを足す** → CoreImage の `CIQRCodeGenerator` で足りる
- **接続確立でトークンを失効させる** → 2 画面目を繋げなくなる。無人アクセスを防ぐのは
  トークンではなくホスト承認（SPEC.md §5.2）
- **ビューアが言語ファイルを実行時に取りに行く** → 単一 HTML で配信する方針と両立しない
- **macOS 側に自前の言語選択を持つ** → システム設定の「アプリごとの言語」が効かなくなる
- **`codesign --deep`** → 入れ子の署名要件を潰す。Apple も非推奨。Frameworks から順に署名する
- **`zip` で圧縮** → 拡張属性を落として署名を壊す。`ditto -c -k --keepParent` を使う

## ハマりどころ

- **キーチェーンの鍵に利用許可を付けないと、アプリ更新の瞬間に HTTPS が黙って死ぬ。**
  署名の変わった実行ファイルから鍵を使うと確認ダイアログが出ようとし、UI を持たない
  検証モードでは**返ってこない**。TCP は繋がるのに TLS ハンドシェイクが完了しない、という
  一番分かりにくい壊れ方をする（`make e2e` の HTTPS 経路だけが落ち続けた）。
  `SecAccessCreate` + `SecACLSetContents(acl, nil, ...)` で解決。
  **`applicationList` は `nil` が「どのアプリでも可」、空配列が「どのアプリも不可」で意味が正反対**
- `SecAccessCreate` 系は deprecated だが、ファイルベースのキーチェーンには代替がない
  （docs/STACK.md §7-7 に確認事項として残した）
- QR を補間して拡大するとモジュールの境界がぼけて読み取り率が落ちる。整数倍に拡大してから
  `Image.interpolation(.none)` で描く
- 上限 fps はエンコーダだけでなく**キャプチャ側にも当てる**（`minimumFrameInterval`）。
  でないと撮ってから捨てるぶんの CPU と電力が無駄になる

## 学び

- 自動再接続と「承認を必ず挟む」は素直に作ると両立しない。**チケットという第 3 の資格情報**を
  挟んで初めて成立する。承認を省く条件（画面ごと・使い切り・10 分・切断で無効）が
  そのまま無人アクセス禁止の担保になっている
- 期限まわり（TTL・レート制限の窓・チケットの寿命）はイニシャライザで注入できるようにした。
  **5 分待たないと確かめられない作りにしない**
- 成功はレート制限の枠を使わない。自動再接続する正しい端末が自分で枠を食い潰す形にしてはいけない
